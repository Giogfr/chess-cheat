# Security Policy

## Supported version

Security fixes are made against the current default branch. Because the project is distributed as an unpacked browser extension, users should review the source and reload the extension after installing a trusted update.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Open a private GitHub Security Advisory for the repository, if that feature is enabled. If private advisories are unavailable, open a public issue that asks for a private contact channel without including exploit steps, tokens, account data, or sensitive site content.

Please include the affected file or feature, browser/version, impact, and a minimal reproduction that does not include cookies or credentials. Do not include personal data or live-game account identifiers.

## Scope notes

The extension has broad website access to inspect boards. Reports about unsafe message handling, origin/frame policy bypasses, unintended network transmission, or unexpected injection on unsupported browser pages are especially relevant. This project does not operate a server and does not intentionally send page data to a project-owned endpoint.
