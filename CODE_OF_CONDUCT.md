# Code of Conduct

The project aims to be a respectful, practical space for discussing browser extensions, chessboard parsing, accessibility, and testing.

Expected behaviour:

- Be respectful and assume good faith while discussing bugs and proposed changes.
- Give actionable, reproducible feedback without personal attacks or harassment.
- Respect privacy: do not post cookies, account tokens, private messages, or identifiable game details in issues or logs.
- Keep contributions focused on improving detection, reliability, accessibility, maintainability, and documented practice/study use.

Unacceptable behaviour includes harassment, discrimination, threats, publishing private information, and deliberately submitting malicious or deceptive changes. Maintainers may edit or remove content that violates these expectations and may close or block repeat offenders.

To report a conduct concern, use a private GitHub contact route available for the repository. Do not put private or sensitive details in public issues.
